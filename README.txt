CampusQuest — AI-Powered Campus Adventure Game
● Problem: Students need fun, engaging ways to connect with campus life.
● Core AI: Trivia/question generation (NLP) + gamification engine.
● MVP:
○ Campus map with 5–10 “locations” (canteen, labs, library, etc.).
○ Visiting a location unlocks an AI-generated quiz or puzzle.
● Data: Mocked campus map + curated trivia dataset.
● Metric: # of levels cleared + student engagement score.
● Stretch Goal: AR mode → scan real campus spots to unlock challenges.
● Learning Angle: Combines NLP, gamification, and interactive design.
